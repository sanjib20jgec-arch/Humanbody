# Brain & Nerves visual review checklist

Status: browser review frames are generated by `tests/browser/brain-review.spec.mjs`; expert visual sign-off remains pending until the Chromium CI job or a browser-capable review environment is available.

## Review frames

The browser job captures these states for both configured viewport projects:

- `brain-explore.png` — default Explore view.
- `brain-peripheral-selected.png` — peripheral-nerves hotspot selected.
- `brain-reflex-ready.png` — reflex simulation before triggering.
- `brain-reflex-stimulus.png` — stimulus step after activation.
- `brain-quiz-feedback.png` — misconception feedback after an incorrect answer.
- `brain-reflex-reduced-motion.png` — reduced-motion simulation state.

The workflow retains these attachments inside the Playwright test-results artifact when the browser job is run.

## Sign-off procedure

1. Run the Chromium CI job or run `npx playwright install --with-deps chromium` in a browser-capable environment.
2. Download the `playwright-diagnostics` artifact.
3. Review the frames at desktop and phone sizes against the acceptance table.
4. Record any label, clipping, orientation, or touch-target issue here before expanding the next internal section.
