# Curriculum alignment — Movement Theater (Phase 91, E3)

Educator-facing map of the Theater actions to (a) India's competency-based
entry-level BPT curriculum (*Kinesiology & Movement Science I & II*, integrated
with anatomy/physiology) and (b) World Physiotherapy entry-level competency
domains. Teaching-aid only — not a certification claim.

The original seven actions shipped in Phase 91; thirteen more were authored in
Phases 113–116 (Directive 19) — see the expansion table below.

| Action | BPT Kinesiology topics touched | WCPT-style domains |
|---|---|---|
| walk | gait cycle (stance/swing, RLA phases), determinants of gait, muscle roles in locomotion, pelvic stabilisation (gluteus medius), ankle rockers | Assessment & intervention (movement analysis); evidence-based practice (normative comparison) |
| run | triple extension, stretch–shortening cycle basics, arm–leg coordination | Assessment & intervention; communication (cueing) |
| jump | countermovement, eccentric–concentric coupling, landing strategy as "muscles as brakes" | Assessment & intervention; ethical practice (loading safety) |
| wave | scapulohumeral rhythm (simplified), abduction prime movers, wrist oscillation | Communication; assessment (upper-limb movement) |
| handshake | elbow-origin oscillation, grip mechanics, wrist lag | Communication; assessment (hand function) |
| chew | TMJ movement, masseter/temporalis roles (simplified), rhythmic motor patterns | Assessment (oral-motor basics) |
| talk | postural control of trunk/head during speech, diaphragm–core coupling (conceptual) | Communication; interprofessional (SLT overlap) |

All are authored/procedural animations, each carrying the standing disclaimer
that quantitative readouts are teaching estimates, not clinical measurements.

Clinical comparison patterns (Phase 92) map to *pathological gait introductions*
in Kinesiology II — explicitly labelled exaggerated teaching caricatures, never
diagnostic.
