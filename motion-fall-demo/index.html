README · how this demo works

This is an educational motion-fall demo, not a clinical or injury-prediction tool. The mannequin is a proxy character with eleven cannon-es rigid bodies connected by limited ConeTwist constraints. A physical-animation spring drives the upright pose during Locomotion, ImpactReact, and Stagger; spring strength ramps down during Collapse so physics takes over smoothly.

The model uses a bounded seed for the impact variation. Replay restores the same seed and parameters and checks fixed-tick body-state hashes. COM, XCoM edge distance, support area, contact count, stability, and trajectory are explanatory overlays.

Safety: neutral impact terms only; no gore, blood, weapons, tactics, targeting, or harm guidance.

Optional asset hook: place assets/character.glb in this folder to display a character asset; physics bone mapping is intentionally documented but not required for the proxy.
