# OpenStax Anatomy & Physiology 2e attribution

The Guided Path Digestion process view uses an adapted local copy of an OpenStax Anatomy & Physiology 2e figure:

- **Figure 23.2, Components of the Digestive System** — `reference/openstax-digestive-23-2.webp`
  - Source: https://openstax.org/books/anatomy-and-physiology-2e/pages/23-1-overview-of-the-digestive-system

Circulation uses the BodyParts3D 4.0 source mesh as its primary 3D reference object and links OpenStax heart anatomy for terminology and structure/function review.

OpenStax Anatomy & Physiology 2e is available under the Creative Commons Attribution 4.0 International license. The source links remain visible in the relevant Guided Path diagrams. The local digestive plate is a reference image; the surrounding interactive overlays, labels, and process animations are Human Biology Lab educational interface work and are explicitly labeled as simplified teaching schematics.
